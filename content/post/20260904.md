Claude Codeで時々「How is Claude doing?」って聞かれる．
だいたいうまく言っているので，Goodと返す．
ただ， Remote Control をしているときに，「How is Claude doing?」は，リモートのもとで動いている実機にしか表示されない．
リモート端末で色々と命令を送っても，反応してくれないのだが，状況がわからない．
要は，止まってしまったとしか見えない．

そこで，settings.json で設定しておいた．
これで大丈夫なはず．

```
  "env": {
    "CLAUDE_CODE_DISABLE_FEEDBACK_SURVEY": "1"
  }

```


追記：

その後，worktree作成の同意を求めるため同様のことが起こったので，ついでに設定しておいた．

```
  "permissions": {
    "allow": [
      "Bash(git worktree:*)",
      "Bash(git add:*)"
    ]
  }
```
